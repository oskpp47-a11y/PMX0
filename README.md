# Pensionados MX v23

App web progresiva (PWA) para gestión de beneficiarios. Funciona sin internet.

## Subir a GitHub Pages
1. Sube todos los archivos a un repositorio
2. Settings → Pages → Source: main → / (root)
3. Abre la URL en Safari → Compartir → "Agregar a pantalla de inicio"

## Archivos
- `index.html` — App completa
- `sw.js` — Service Worker (offline)
- `manifest.json` — Config PWA
- `icon-192.png` / `icon-512.png` — Íconos
